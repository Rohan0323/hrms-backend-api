# Human Resource Management System (HRMS)

A Human Resource Management System for managing employee records, attendance, salary, leave, and project allocation.

# Overview

The system provides role-based access for **Administrators, Employees, Project Managers, and Accounts Managers** to manage employee and organizational operations.

The application is built using **Node.js, Express, MongoDB, HTML, CSS, Bootstrap, and JavaScript**.

# Key Features

- Role-Based Access Control
- Employee Management
- Attendance Management
- Leave Management
- Salary Management
- Employee Profiles & Records
- Project Allocation
- Performance Appraisal
- Payslip & Bonus Management

# DevOps & AWS Deployment

The application was containerized and deployed using modern DevOps practices.

**Deployment Stack:**

- AWS EC2
- Docker
- Docker Compose
- GitHub Actions
- MongoDB Atlas
- AWS IAM
- AWS Secrets Manager
